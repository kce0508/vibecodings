# 👻 Ghost Signal

## 🎮 게임 소개

**Ghost Signal**은 보이지 않는 유령을 피해 열쇠를 찾고 출구로 탈출하는 미니 공포 게임입니다.

유령은 화면에 보이지 않으며, 플레이어는 오직 **신호(Ghost Signal)** 를 통해 유령의 위치를 추측해야 합니다.

---

# 🎯 게임 목표

- 맵 안에서 **열쇠(Key)** 를 찾는다.
- 열쇠를 획득한 후 **출구(Door)** 로 이동한다.
- 유령에게 잡히기 전에 탈출하면 클리어.

---

# 🎮 조작법

| 키 | 기능 |
|----|------|
| ⬆️ | 위 이동 |
| ⬇️ | 아래 이동 |
| ⬅️ | 왼쪽 이동 |
| ➡️ | 오른쪽 이동 |
| Enter | 게임 시작 |
| R | 다시 시작 |

# 🧱 맵 구성

| 👻 | 유령 (화면에는 보이지 않음) |

# 👻 Ghost Signal 시스템

유령은 절대 화면에 표시되지 않습니다.

대신 플레이어와의 거리를 계산하여 신호를 출력합니다.

### 거리 단계

| 거리 | 표시 |
|------|------|
| 멀리 | ... |
| 조금 가까움 | ! |
| 가까움 | !! |
| 위험 | !!! |
| 매우 위험 | DANGER |

---

# 📍 방향 신호

유령이 있는 방향을 화살표로 알려줍니다.

예시

```
↑
```

유령이 위쪽

```
↖
```

왼쪽 위

```
→
```

오른쪽

```
↓
```

아래

플레이어는 이 정보를 이용해 반대 방향으로 도망가야 합니다.

---

# 👻 유령 AI

- 일정 시간마다 이동
- 플레이어 방향으로 추적
- 벽을 우회하여 이동
- 플레이어와 같은 칸에 도착하면 게임 오버

---

# 🔑 열쇠 시스템

- 랜덤 위치에 생성
- 획득하면 HUD가 변경

```
Key : ✅
```

---

# 🚪 출구 시스템

열쇠가 없는 상태

```
문이 잠겨 있습니다.
열쇠를 먼저 찾으세요.
```

열쇠 획득 후

출구 도착

```
🎉 탈출 성공!
```

---

# 💀 게임 오버

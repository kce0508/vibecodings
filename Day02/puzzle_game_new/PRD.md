# 퍼즐게임 PRD

## 1. 프로젝트 개요

- 프로젝트명: 간단한 동물 맞추기 게임
- 형식: 브라우저 기반 카드 짝맞추기 퍼즐 게임
- 목표: 같은 그림 2장을 찾아 보드를 모두 완성하는 캐주얼 게임을 제공한다.

## 2. 핵심 목표

- 사용자가 시작 화면에서 게임을 시작할 수 있어야 한다.
- 난이도에 따라 보드 크기와 제한 시간이 달라져야 한다.
- 모든 카드를 맞추면 다음 단계로 진행되어야 한다.
- 마지막 단계를 완료하면 게임 클리어 화면을 보여줘야 한다.
- 제한 시간 내에 모두 맞추지 못하면 게임 오버 화면을 보여줘야 한다.

## 3. 게임 규칙

### 3.1 기본 규칙
- 카드를 클릭하면 해당 카드의 그림이 공개된다.
- 두 장의 카드가 같은 그림이면 매칭 성공으로 처리한다.
- 다른 그림이면 다시 뒤집힌다.
- 이미 맞춘 카드는 다시 선택할 수 없다.

### 3.2 점수 규칙
- 같은 그림을 맞출 때마다 점수는 10점씩 증가한다.
- 시도 횟수는 두 장의 카드를 고를 때마다 1회 증가한다.

### 3.3 시간 규칙
- 게임은 각 단계마다 제한 시간이 존재한다.
- 시간이 0이 되면 즉시 GAME OVER 처리한다.
- 제한 시간은 난이도별로 다르게 설정한다.

## 4. 난이도 시스템

게임은 4단계 난이도를 지원한다.

- 쉬움: 3x3, 제한 시간 45초
- 중간 1: 4x4, 제한 시간 60초
- 중간 2: 5x5, 제한 시간 75초
- 어려움: 6x6, 제한 시간 90초

### 난이도 선택 규칙
- 시작 전에는 콤보박스로 난이도를 선택할 수 있다.
- 게임 시작 후에는 난이도 변경을 막는다.
- 단계 클리어 시 다음 난이도로 자동 이동한다.
- 마지막 난이도인 어려움을 클리어하면 GAME CLEAR로 종료한다.

## 5. 화면 구성

### 5.1 시작 화면
- 처음 진입 시 게임 시작 화면을 보여준다.
- 시작하기 버튼을 누르면 게임이 시작된다.
- 시작 화면에는 게임 제목과 안내 문구를 표시한다.

### 5.2 게임 화면
- 상단에 시도 횟수, 점수, 남은 시간, 난이도를 표시한다.
- 오른쪽 버튼은 시작 전에는 시작하기, 게임 중에는 처음으로를 표시한다.
- 중앙에는 퍼즐 보드를 표시한다.
- 하단에는 상태 메시지를 표시한다.

### 5.3 단계 전환 화면
- 현재 단계를 모두 완료하면 LEVEL UP!! 메시지를 화면 중앙에 표시한다.
- 잠시 후 다음 단계로 자동 전환한다.
- 전환 시 단계 안내 문구를 함께 보여준다.

### 5.4 종료 화면
- 마지막 단계를 완료하면 GAME CLEAR!! 메시지를 표시한다.
- 시간이 다 되면 GAME OVER 메시지를 표시한다.
- 종료 화면에는 처음으로 이동하는 버튼을 제공한다.

## 6. UI 요구사항

- 게임 제목과 안내 문구는 한국어로 표시한다.
- 난이도 콤보박스의 항목은 쉬움, 중간 1, 중간 2, 어려움으로 표기한다.
- 퍼즐 카드의 앞면은 귀여운 동물 그림으로 구성한다.
- 카드 뒷면은 동일한 스타일의 공통 디자인을 사용한다.
- 레벨 업, 게임 클리어, 게임 오버 메시지는 화면 중앙 오버레이로 표시한다.

## 7. 기능 요구사항

- 시작 버튼을 누르기 전에는 게임이 진행되지 않아야 한다.
- 시작 후에는 타이머가 동작해야 한다.
- 카드 매칭이 성공하면 점수가 10점 증가해야 한다.
- 모든 카드를 맞추면 다음 단계로 넘어가야 한다.
- 마지막 단계 완료 시 게임 클리어 처리를 해야 한다.
- 제한 시간 초과 시 게임 오버 처리를 해야 한다.
- 종료 후 처음으로 돌아가면 시작 화면이 다시 보여야 한다.

## 8. 데이터 및 상태

- 현재 단계
- 현재 시도 횟수
- 현재 점수
- 남은 시간
- 매칭된 카드 수
- 게임 시작 여부
- 게임 종료 여부

## 9. 확장 고려사항

- 사운드 효과 추가
- 최고 점수 저장
- 단계별 배경 효과 강화
- 모바일 조작성 개선
- 애니메이션 보강

## 10. 성공 기준

- 사용자가 시작 화면에서 자연스럽게 게임을 시작할 수 있다.
- 단계별로 난이도가 상승하는 흐름이 명확하다.
- LEVEL UP, GAME CLEAR, GAME OVER가 의도한 시점에 잘 표시된다.
- 점수와 시간 규칙이 안정적으로 동작한다.
- 브라우저에서 문제 없이 실행된다.
